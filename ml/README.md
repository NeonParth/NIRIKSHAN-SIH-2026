# Future analysis modules

These directories mark planned Phase 2+ boundaries. They are **not implemented** in Phase 1.

- `anomaly_detection/` — statistical / model-based anomaly signals
- `computer_vision/` — image similarity, perceptual hashing, before/after checks
- `nlp/` — project-name and description similarity

Phase 1 uses a deterministic, YAML-configured rule engine only. Do not treat this folder as a trained model.
